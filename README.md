# Drift Points System

Earn money while drifting in FiveM with this engaging drift points system.

## Features

- Earn points while drifting in vehicles
- Track drift performance and reward players

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Add `start driftPointSystem` to your server.cfg file
4. Import the database.sql file into your MySQL database

## Usage

- Players can start drifting in vehicles to earn points
- Points are automatically added to the player's account

## Configuration

The script can be configured in the `config.lua` file. You can adjust the minimum and maximum speed for earning points, the point multiplier, the cooldown between points, and the reward amount.
